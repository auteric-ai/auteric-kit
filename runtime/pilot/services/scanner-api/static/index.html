MERCHANT FAQ

Questions about AI shopping readiness.

Can ChatGPT find my products?

Auteric checks public discovery and catalog signals that AI shopping systems may rely on. No outside scanner can guarantee inclusion in a third-party experience.

How do I know if my store is ready?

Run the public URL scan to review crawlability, catalog data, protocol availability, checkout signals and high-level security posture.

What is an AI shopping readiness score?

It is an evidence-based summary of visibility, product data, protocols, checkout signals and safely observable security checks.

What is UCP?

UCP is a commerce protocol surface that can describe merchant capabilities to agents. Auteric validates public UCP evidence when available.

Does Auteric make a real purchase?

No. The public scan never submits an order, captures payment or changes inventory.

What security information is public?

High-level scores and generic issue categories. Potentially sensitive details remain protected until ownership is verified.
