# A U T E R I C brand

Use the official Auteric mark with the uppercase wordmark below in any kit page,
setup surface, documentation or generated merchant interface.

```css
.logo {
  font-family: "Inter", "Helvetica Neue", Arial, sans-serif;
  font-size: 25px;
  font-weight: 600;
  letter-spacing: 0.28em;
  text-transform: uppercase;
}
```

The approved wordmark is `A U T E R I C`. Keep the letter spacing between
`0.25em` and `0.32em`, retain the purple Auteric mark, and do not replace it
with a text `A` in product surfaces.
